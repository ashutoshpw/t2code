# Spaces

Enable **Spaces** in **Settings → Labs** for the environment you want to use. It is off by default. Select one environment if another selected server needs an update.

Open Spaces from the app rail, the sidebar's navigation controls when the rail is hidden, or **Open Spaces** in the command palette. You can assign a shortcut in Settings → Keybindings; none is assigned by default.

Browse existing spaces and pages in the selected environment. The current view shows page details read-only. Use **Next pages** or **Next spaces** to browse another window. On an environment that supports nested pages, expand a page to browse its direct children. Collapse branches to release them when the navigation limit is reached. Refresh pages if another device moves or renames them.

After opening a saved chat, visit a page and choose **Open beside chat** to keep its details in a panel. Threads returns to your previous chat. Page links can include a block target in the URL query. The page location shows its current space and parent pages; refresh the location if it changes elsewhere.

Turning Spaces off keeps its data. Reading pages requires the destination environment's read permission; changing the setting requires permission to change its settings.
